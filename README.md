# Masar (مسار) - Modern Project Management System

Masar is a premium, developer-first project management system designed with a high-end, clean, and minimalist aesthetic. It is optimized for clarity, speed, and focus, providing teams with a powerful tool to manage their daily workflows.

## 🌟 Key Features

- **Advanced Task Management**: Organize work efficiently using multiple views, including Kanban boards and detailed List views.
- **Project Tracking**: Manage multiple workspaces, track overall completion percentages, and visualize project-specific metrics.
- **Team Collaboration**: View team members, assign tasks, and monitor active workloads and capacity.
- **Interactive Calendar**: Visual scheduling and deadline tracking with dynamic Month and Week grids.
- **Subtasks & Comments**: Break down large tasks into smaller subtasks and collaborate via rich comments on specific tasks.
- **Real-time Activity Feed**: Keep track of what's happening across your workspace with timeline logs.
- **100% Responsive Design**: A flawless, native app-like experience perfectly optimized for desktop, tablet, and mobile devices.


## 🤝 The Collaboration (Mohamed + AI)

This project is a testament to the power of pair programming. It was built through a highly efficient collaboration between **Mohamed** and an **AI Assistant**:

- **Mohamed**: Acted as the Lead Architect and Product Manager—planning features, reviewing code, making architectural decisions, defining the UI/UX vision, and steering the overall direction of the platform.
- **The AI**: Handled the execution—writing the codebase, refactoring modular components, implementing state management, and ensuring pixel-perfect responsive designs based on Mohamed's exact specifications.

# مسار (Masar) - نظام إدارة المشاريع الحديث

"مسار" هو نظام متقدم لإدارة المشاريع مصمم خصيصاً للمطورين، يتميز بواجهة نظيفة، سريعة، وراقية. تم تحسينه ليقدم أعلى درجات الوضوح والسرعة والتركيز، ليكون الأداة الأقوى للفرق لإدارة سير عملهم اليومي.

## 🌟 أهم المميزات

- **إدارة مهام متقدمة**: نظم عملك بكفاءة باستخدام طرق عرض متعددة، مثل لوحات الكانبان (Kanban) والقوائم المفصلة.
- **تتبع المشاريع**: أدر مساحات عمل متعددة، وراقب نسب الإنجاز والمقاييس الخاصة بكل مشروع.
- **تعاون الفريق**: استعرض أعضاء فريقك، وعيّن المهام، وراقب طاقة العمل والمهام النشطة لكل فرد.
- **تقويم تفاعلي**: جدولة مرئية وتتبع للمواعيد النهائية من خلال عرض تفاعلي للشهور والأسابيع.
- **مهام فرعية وتعليقات**: قسّم المهام الكبيرة لمهام أصغر، وتعاون مع فريقك عبر نظام تعليقات متقدم.
- **سجل نشاطات لحظي**: ابقَ على اطلاع بكل ما يحدث عبر سجل زمني (Activity Feed).
- **تصميم متجاوب 100%**: تجربة استخدام خالية من العيوب، تبدو وكأنها تطبيق أصلي (Native) على شاشات الكمبيوتر، الأجهزة اللوحية، والهواتف المحمولة.


## 🤝 التعاون (محمد + الذكاء الاصطناعي)

هذا المشروع هو شهادة حية على قوة البرمجة الزوجية بين الإنسان والذكاء الاصطناعي. تم بناء هذا النظام عبر تعاون عالي الكفاءة بين **محمد** ومساعد **الذكاء الاصطناعي**:

- **محمد**: قام بدور المهندس المعماري الرئيسي ومدير المنتج — حيث خطط للميزات، راجع الأكواد، اتخذ القرارات المعمارية، حدد الرؤية الخاصة بتجربة المستخدم (UI/UX)، ووجه المسار العام للمنصة.
- **الذكاء الاصطناعي**: تولى مهمة التنفيذ — بكتابة الأكواد، بناء نظام إدارة الحالة، وضمان دقة التصميم وتجاوبه التام 100% بناءً على تعليمات محمد الدقيقة.
